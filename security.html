Security

Last updated: 2 September 2026

We take practical steps to keep the service and your data reasonably secure. This page describes those measures and known limitations.

1. Data in Transit

All traffic between your browser and the hosting provider, and between the application and the Supabase database, occurs over HTTPS.

2. Database Access

Short-link records are stored in a PostgreSQL database managed by Supabase. Access from the browser uses the public anon key together with Row Level Security (RLS) policies that only permit insert and select of link records, plus a restricted function for incrementing click counts.

The service key is never exposed in client-side code.

3. Short Codes

Short codes are generated with a cryptographically secure random number generator. The default length provides a large space that makes casual guessing impractical. Collisions are handled by retrying with a new code.

4. Abuse Prevention

We rely on rate limiting at the database and hosting layers, and we reserve the right to disable links or block traffic that appears abusive. You remain responsible for the destinations of the links you create.

5. Limitations

  • This is a free public shortener. It is not designed for high-security or regulated workloads.
  • Anyone who obtains a short code can resolve it. Do not put secrets in the path or query string of a long URL if you care about confidentiality.
  • Click counts are best-effort and can be inflated by bots.
  • We do not currently offer password-protected links or two-factor protection on individual short URLs.

6. Reporting Security Issues

If you discover a vulnerability, please report it privately through the project repository's security advisory or issue tracker. We appreciate responsible disclosure and will work to address valid reports promptly.

7. Third-Party Services

We depend on Supabase for the database and on a static host (for example GitHub Pages) for the front end. Their security practices apply to those layers. Optional QR code generation may use a third-party image API; that API only receives the short URL string.
