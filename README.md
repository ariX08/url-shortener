# Shortly

Professional URL shortener with click tracking, QR codes, and Supabase storage.

**made by [ARITRA.DESIGN](https://arix.faltuworkonly91.workers.dev/)**

## Setup

1. Create a free project at [supabase.com](https://supabase.com)
2. Run `schema.sql` in the SQL Editor
3. Put your Project URL and anon key in `config.js`
4. Open `index.html` or deploy to GitHub Pages

## Deploy

Enable GitHub Pages on this repo (Settings → Pages → main branch / root).
