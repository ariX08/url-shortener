# Shortly

Professional URL shortener with click tracking, QR codes, link expiry, and Supabase storage.

**made by [ARITRA.DESIGN](https://arix.faltuworkonly91.workers.dev/)**

## Features

- Short links with optional expiry (12h / 24h / Forever)
- Live click counts
- QR codes
- Cookie preferences
- Privacy, Terms, Security, Cookie Policy pages

## Setup

1. Create a free project at [supabase.com](https://supabase.com)
2. Run `schema.sql` in the SQL Editor (full file)
3. Put your Project URL and anon key in `config.js`
4. Open locally or enable GitHub Pages

## Deploy

Settings → Pages → Deploy from branch `main` / root.

Short links resolve via `r.html?c=CODE`.
